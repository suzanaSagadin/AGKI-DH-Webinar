# Eine praktische Einführung in LangChain.

Lern- und Beispielmaterial für ein Webinar am 23.10.2024 der DHd-AG *Angewandte Generative KI in den Digitalen Geisteswissenschaften* (AGKI-DH).

Die Beispieldaten stammen aus dem Projekt **ManMax** (*Managing Maximilian*) und werden hier zu Demonstrations- und Lehrzwecken verwendet.

### Notebooks

- **LangChain.ipynb**: Hauptnotebook zur Einführung in LangChain.
- **Chain.ipynb**: Beispiele zum Aufbau von Chains.
- **RAG_Chain.ipynb**: Beispiele zu Retrieval-Augmented Generation (RAG).

### Data

Beispieldaten aus dem ManMax-Projekt:

- **data/examples_NER.json**: Beispieldaten für Named Entity Recognition.
- **data/examples.json**: Beispieldaten für die Satz- bzw. Statement-Extraktion.
- **data/names_ids.csv**: CSV-Datei mit Namen und IDs.
